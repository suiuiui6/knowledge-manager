# Contributor Covenant Code of Conduct

We build a respectful, welcoming, and evidence-oriented community. Be
constructive, assume good faith, and do not harass, discriminate, attack people,
or publish private information.

Report unacceptable behavior privately through the repository owner's GitHub
profile. Maintainers may edit, remove, or reject contributions that violate this
code. See the full covenant at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
