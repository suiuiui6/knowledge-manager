# 概述

We deploy and manage applications on Kubernetes to handle scaling, networking, and configuration management.

# 细节

We leverage Pods (smallest deployable units), Deployments (manage replica sets and rolling updates), Services (expose pods reliably), ConfigMaps (non-sensitive configuration), and Secrets (sensitive data).
