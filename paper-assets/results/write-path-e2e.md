# 写路径端到端验证模板

当前版本是模板，不包含新的写路径结果。该文件用于补齐目前弱于读路径、搜索路径和协议路径的证据。

## 最小验证链路

| 步骤 | 预期证据 | 状态 |
|---|---|---|
| create module | 新模块进入 staging 或 draft 状态 | 待运行 |
| update module | 修改可持久化、可审查 | 待运行 |
| review module | 审核记录可追踪 | 待运行 |
| approve module | 模块进入 approved store，索引更新 | 待运行 |
| search-after-write | 新模块可被搜索发现 | 待运行 |
| load-after-write | 新模块可被 CLI/MCP 加载 | 待运行 |
| delete 或 archive | 模块状态变化可追踪，活跃索引符合预期 | 待运行 |

## 论文写法边界

在结果未补齐前，只能写“写路径证据弱于读路径”。如果完成上述链路，可写“补充验证覆盖关键写路径”，但仍不应与协议路径和搜索路径写成同等充分，除非有稳定重复运行记录。
