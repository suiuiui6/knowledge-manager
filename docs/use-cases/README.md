# Reproducible walkthroughs

These walkthroughs use the public CLI and do not depend on a hosted service.
They are meant to be run against a fresh checkout or a local install.

1. [Claude Code](claude-code.md) - connect the demo knowledge base over MCP.
2. [DeepSeek runbooks](deepseek-runbooks.md) - extract a runbook, review it,
   then search it.
3. [Reviewed context](reviewed-context.md) - see why staging is excluded from
   retrieval until a human approves it.

If a step needs an LLM provider, it is called out explicitly. The demo commands
and the review/search path do not require an API key.
