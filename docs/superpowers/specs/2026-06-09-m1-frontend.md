# M1 Frontend Spec — Web UI 只读模式

> Phase 5 M1 | 2026-06-09 | 依赖: M1 Backend API

## 设计目标

- **双模式:** React完整UI + 零构建回退UI
- **三栏布局:** 左侧知识树 | 中间内容 | 右侧图谱
- **只读:** 浏览、搜索、查看模块、探索图谱
- **M1 不包含:** 对话搜索(M2)、编辑(M6)、知识树推理(M3)

## 信息架构

```
/                         → Dashboard (统计卡片 + 健康趋势 + 最近活动)
/search?q=<query>         → 搜索结果列表
/module/:cat/:id          → 模块详情 (JSON渲染)
/graph                    → 全量知识图谱 (力导向图)
/graph/:cat/:id           → 模块局部图谱
```

路由在 React 模式下由 `react-router` 管理；零构建模式下用 htmx 的 `hx-get` + `hx-target` 实现无刷新页面切换。

### API 客户端 (`src/ui/lib/api.ts`)

```typescript
const BASE = '';  // 同源，无需配置

async function get<T>(path: string, params?: Record<string, string>): Promise<T> {
  const url = new URL(path, window.location.origin);
  if (params) {
    Object.entries(params).forEach(([k, v]) => url.searchParams.set(k, v));
  }
  const res = await fetch(url);
  if (!res.ok) {
    const err = await res.json().catch(() => ({ error: res.statusText }));
    throw new ApiError(res.status, err.error);
  }
  return res.json();
}

async function post<T>(path: string, body: unknown): Promise<T> {
  const res = await fetch(path, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body),
  });
  if (!res.ok) {
    const err = await res.json().catch(() => ({ error: res.statusText }));
    throw new ApiError(res.status, err.error);
  }
  return res.json();
}
```

### 核心 Hooks

```typescript
// useTree.ts
function useTree() {
  const [tree, setTree] = useState<TreeNode | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    get<TreeNode>('/api/tree')
      .then(setTree)
      .catch(e => setError(e.message))
      .finally(() => setLoading(false));
  }, []);

  return { tree, loading, error };
}

// useSearch.ts — 搜索防抖 (300ms)
function useSearch() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState<SearchResponse | null>(null);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    if (!query.trim()) { setResults(null); return; }
    const timer = setTimeout(() => {
      setLoading(true);
      post<SearchResponse>('/api/search', { query, top_k: 10 })
        .then(setResults)
        .finally(() => setLoading(false));
    }, 300);
    return () => clearTimeout(timer);
  }, [query]);

  return { query, setQuery, results, loading };
}

// useGraph.ts
function useGraph(centerModule?: string) {
  const [graph, setGraph] = useState<GraphData | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const endpoint = centerModule ? `/api/graph/${centerModule}` : '/api/graph';
    get<GraphData>(endpoint)
      .then(setGraph)
      .finally(() => setLoading(false));
  }, [centerModule]);

  return { graph, loading };
}
```

### KnowledgeTree.tsx — 左侧导航树

**数据源:** `useTree()` → `/api/tree`

**M1 行为:**
- 默认展开所有 category 节点
- 点击 module 节点 → 导航到 `/module/:cat/:id`
- 当前活跃模块高亮
- category 节点可折叠/展开（默认展开）

**M1 不支持 (M3才加):**
- 拖拽排序
- 树内过滤搜索
- section 级别节点

```typescript
interface TreeNodeData {
  id: string;
  type: 'root' | 'category' | 'module' | 'section';
  title: string;
  summary: string;
  path: string;
  children: TreeNodeData[];
  module_count?: number;  // category节点
  tags?: string[];
  status?: string;
}

function KnowledgeTree({ tree, activeModule }: { tree: TreeNodeData | null; activeModule?: string }) {
  if (!tree) return <div>Loading...</div>;
  return (
    <nav className="tree-nav">
      {tree.children.map(cat => (
        <CategoryNode key={cat.id} node={cat} activeModule={activeModule} />
      ))}
    </nav>
  );
}

function CategoryNode({ node, activeModule }: { node: TreeNodeData; activeModule?: string }) {
  const [expanded, setExpanded] = useState(true);  // M1默认展开
  return (
    <div className="tree-category">
      <div className="tree-category-header" onClick={() => setExpanded(!expanded)}>
        <span className="tree-arrow">{expanded ? '▾' : '▸'}</span>
        <span className="tree-icon">📁</span>
        <span className="tree-title">{node.title}</span>
        <span className="tree-count">{node.module_count}</span>
      </div>
      {expanded && node.children.map(mod => (
        <ModuleNode key={mod.id} node={mod} active={activeModule === mod.id} />
      ))}
    </div>
  );
}
```

### ModuleViewer.tsx — 模块内容渲染

**数据源:** `fetch('/api/modules/:cat/:id')` → Module 对象

**渲染策略 (M1):**
- Module JSON 的 content 字段逐区域渲染
- `overview` → 作为摘要段落
- `details` → 作为正文
- `examples` → 代码块（自动检测语言）
- `caveats` → 警告框样式
- `references` → 链接列表

**MarkdownRenderer (M1 简化版):**
- 将纯文本（非Markdown）渲染为 HTML
- 支持基本的代码块检测（``` 包裹的文本 → `<pre><code>`）
- URL 自动转链接
- **M5 增强:** 完整 Markdown 解析 + `[[wikilinks]]` 渲染

```typescript
function ModuleViewer({ category, moduleId }: { category: string; moduleId: string }) {
  const [module, setModule] = useState<Module | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    setLoading(true);
    get<Module>(`/api/modules/${category}/${moduleId}`)
      .then(setModule)
      .catch(e => setError(e.message))
      .finally(() => setLoading(false));
  }, [category, moduleId]);

  if (loading) return <Skeleton />;
  if (error) return <ErrorDisplay message={error} />;
  if (!module) return null;

  return (
    <article className="module-viewer">
      <ModuleMeta module={module} />
      <h1>{module.title}</h1>
      <p className="module-summary">{module.summary}</p>
      <section className="module-overview"><ContentBlock text={module.content.overview} /></section>
      <section className="module-details"><ContentBlock text={module.content.details} /></section>
      {module.content.examples && <section className="module-examples"><ContentBlock text={module.content.examples} /></section>}
      {module.content.caveats && <section className="module-caveats"><WarningBox text={module.content.caveats} /></section>}
      {module.content.references && <section className="module-references"><ReferencesList text={module.content.references} /></section>}
      <RelatedModules modules={module.metadata.related_modules} />
    </article>
  );
}
```

### GraphView/ForceGraph.tsx — 知识图谱

**数据源:** `useGraph(centerModule?)` → `/api/graph` 或 `/api/graph/:cat/:id`

**M1 使用 Cytoscape.js:**
- 布局: `cose` (力导向)
- 节点颜色: category → 颜色映射
- 节点大小: `in_degree + out_degree` 映射到 20px–80px
- deprecated 节点: 虚线边框 (border-style: dashed)
- archived 节点: opacity 0.4
- 边: `weight * 5` 映射线宽
- 悬停高亮邻居
- 点击节点 → 导航到 `/module/:cat/:id`

```typescript
const CATEGORY_COLORS: Record<string, string> = {
  'auth': '#3b82f6',
  'backend': '#10b981',
  'deployment': '#f59e0b',
  'architecture': '#8b5cf6',
  'general': '#6b7280',
};

function ForceGraph({ data, onNodeClick }: { data: GraphData; onNodeClick: (id: string) => void }) {
  const containerRef = useRef<HTMLDivElement>(null);
  const cyRef = useRef<cytoscape.Core | null>(null);

  useEffect(() => {
    if (!containerRef.current) return;

    const cy = cytoscape({
      container: containerRef.current,
      elements: [
        ...data.nodes.map(n => ({
          data: {
            id: n.id,
            label: n.label,
            category: n.category,
            size: clamp(20 + (n.in_degree + n.out_degree) * 5, 20, 80),
            color: CATEGORY_COLORS[n.category] || '#6b7280',
            status: n.status,
          },
        })),
        ...data.edges.map((e, i) => ({
          data: {
            id: `e${i}`,
            source: e.source,
            target: e.target,
            weight: e.weight,
          },
        })),
      ],
      style: [
        { selector: 'node', style: { 'background-color': 'data(color)', 'width': 'data(size)', 'height': 'data(size)', 'label': 'data(label)', 'font-size': '9px', 'text-valign': 'bottom', 'text-halign': 'center', 'text-margin-y': 6 } },
        { selector: 'node[status="deprecated"]', style: { 'border-color': '#f59e0b', 'border-style': 'dashed', 'border-width': 2 } },
        { selector: 'node[status="archived"]', style: { 'opacity': 0.35 } },
        { selector: 'edge', style: { 'width': 'mapData(weight, 0, 1, 1, 4)', 'line-color': '#94a3b8', 'opacity': 0.5, 'curve-style': 'bezier' } },
      ],
      layout: { name: 'cose', animate: false, nodeRepulsion: 8000, idealEdgeLength: 120, gravity: 0.3 },
    });

    cy.on('click', 'node', evt => onNodeClick(evt.target.id()));
    cy.on('mouseover', 'node', evt => evt.target.closedNeighborhood().difference(cy.elements()).addClass('dimmed'));
    cy.on('mouseout', 'node', () => cy.elements().removeClass('dimmed'));

    cyRef.current = cy;
    return () => cy.destroy();
  }, [data]);

  return <div ref={containerRef} style={{ width: '100%', height: '600px' }} />;
}
```

### 零构建模式的限制

| 功能 | React模式 | 零构建模式 |
|------|----------|-----------|
| 知识树浏览 | ✅ 可折叠/展开 | ✅ 可折叠/展开 (Alpine.js) |
| 模块阅读 | ✅ Markdown渲染 | ✅ 纯文本 + 基础格式化 |
| 搜索 | ✅ 防抖搜索 | ✅ 防抖搜索 (htmx) |
| 知识图谱 | ✅ Cytoscape.js 力导向图 | ❌ 不在此模式中提供 |
| 统计仪表盘 | ✅ Charts | ✅ 数字 + 列表 |
| URL路由 | ✅ react-router | ⚠️ htmx无URL更新 |
| 响应式布局 | ✅ CSS Grid | ✅ Flexbox基础 |

## 实现顺序 (M1内部)

1. **API 层** (`http_server.py` + `schemas.py`新增) — 后端起，前端可并行开发
2. **零构建回退UI** (`ui_fallback.py`) — 立即可用，即使没有Node.js
3. **React脚手架** (package.json + vite.config + tailwind + types)
4. **Layout + Sidebar + KnowledgeTree** — 浏览体验
5. **ModuleViewer** — 内容阅读
6. **Dashboard** — 首页仪表盘
7. **SearchResults** — 搜索体验
8. **GraphView** — 图谱可视化
9. **响应式调优** — 移动端适配
